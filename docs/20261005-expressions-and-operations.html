1. Concept and notation

Arithmetic expressions represent a precise sequence of operations. Python uses ** for powers and parentheses to group terms. Julia uses ^ for powers. A number alone has no physical unit.

2. Worked example (different from the exercise)

For a square of side 3, area is 3**2 = 9. In (2+3)*4, grouping gives 20; 2+3*4 gives 14.

Explain the example in words before proceeding.

Code

result2 = a + b*c

Result with grouping is 20
Result without grouping is 14
