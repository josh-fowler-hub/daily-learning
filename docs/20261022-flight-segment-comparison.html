Lesson 018: Compare two flight segments

Learning goal: Make a consistent comparison of two constant-speed segments using distance, ratios, signed percent changes and scientific notation.

Prerequisites: Lessons 005-017: arithmetic, units, variables, functions, paired lists, graphs, ratios, percentages and scientific notation. Time: 20-30 minutes; optional reading 5 minutes separately. Python 3; Matplotlib for the graph. This is consolidation; no new computational method is required.

2. Model and separate worked example

Supplied model: distance traveled d=vt for constant nonnegative speed v and elapsed time t. Units are (m/s)s=m. Each segment has its own local clock starting at zero; each distance starts at zero. We compare independent segments, not a connected trajectory. Acceleration, turning, wind and fuel consumption are omitted. The model does not establish flight feasibility.

Separate example: two fictional rail-cart runs have v1=4 m/s, t1=5 s and v2=6 m/s, t2=5 s. Their distances are 20 and 30 m. The distance ratio is 30/20=1.5 and the distance change relative to run 1 is 100(30-20)/20=50%. The shared duration makes the speed and distance ratios equal. In normalized notation, the distances are 210^1 and 3*10^1 m.

Reminder: Python uses * for multiplication, / for division, ** for powers, and literals such as 2e1 for scientific notation. Enter a short table as explicit values and function calls; loops are unnecessary. A distance function has a return expression such as speed_mps*time_s. The graph command plt.plot(times_s, distances_m, marker=“o”, label=“Run”) connects paired entries; use axis labels, legend and plt.show().

3. Your assigned comparison

Use these fictional educational inputs, with no data download needed: Segment A: constant speed 120 m/s for 200 s. Segment B: constant speed 150 m/s for 160 s.

  1. Predict whether B travels farther. State your reasoning before calculating: both speed and duration change.
  2. Store the four inputs in named variables and calculate d_A and d_B. Record input and output units.
  3. Use A as the reference. Calculate B/A ratios for speed, duration and distance. Then calculate signed percent changes for all three quantities using 100*(B-A)/A. Make a Markdown table with A, B, ratio and percent-change columns. Include units in the A and B entries.
  4. Express each calculated distance in normalized scientific notation and e notation. Reconstruct the decimal values to check them. Also express the distances in km, using 1000 m=1 km.
  5. Define two distance functions using the supplied speeds. Build explicit time/distance pairs for A at [0,100,200] s and B at [0,80,160] s. Plot both distances against local elapsed time with markers, labels and a legend. Explain the slopes and the endpoints. Do not extend either line beyond its stated duration.
  6. Explain whether faster alone determines farther. Compare your prediction with your table and graph; identify which two inputs determine each endpoint.

Graph, checks and interpretation

Success checks: direct substitution agrees with a function call; zero time gives zero distance; table entries match plotted markers; final points use each segment’s own duration; changing notation preserves values and units. Multiply the speed ratio by the duration ratio and compare with the distance ratio. Explain this check using d=v*t; do not merely report a number.

Use unchanged-value and doubled-value examples to check your percent-change calculation, as in Lesson 016. Restart the kernel and run completed cells top-to-bottom. These checks establish consistency with the supplied model, not agreement with actual flight data.

Write three sentences: what changed, relative to which reference, and what remained the same. Explain why adding the speed and duration percentage changes is not generally a valid way to find the distance percentage change. Use your computed ratios as evidence; no symbolic derivation is required.

Optional stretch: keep B’s duration fixed but change its speed to 180 m/s. Predict the direction of the distance change, then repeat only the endpoint comparison.

Remediation: if the percentage is unclear, label A explicitly as the reference. If the graph is confusing, print three paired points before plotting. If units are unclear, cancel (m/s)*s on paper. Record comfortable / needs practice for units, ratios, reference choice and graph interpretation.
