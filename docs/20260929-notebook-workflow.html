Lesson 001: Notebook workflow and reproducibility

Learning goal: Notebook workflow and reproducibility.

Prerequisites: None.

Time: 15-30 minutes. Status: Complete

1. Concept and notation

A notebook contains explanatory text cells and executable code cells. A kernel stores state between executions. Run top-to-bottom to reproduce a result; a comment beginning with # is documentation, not an instruction to Python. print displays an object.

x = [1, 2, 3, 4, 5, -1]  # This is a vector of numbers.

function ensure_positivity_sqrt(x)
    if x < 0
        error("x must be non-negative")
    else
        return sqrt(x)
    end
end

for i in x
    println("The square root of $i is $(ensure_positivity_sqrt(i))")
end
